# frontend

AtelierPopo 스토어프론트 프로토타입입니다. Next.js 15 / React 19로 만든 정적 UI이며, 상품 데이터는 `src/data/products.ts`에 들어 있고 이미지는 외부 `readdy.ai` URL을 사용합니다.

## 실행

```bash
npm ci
npm run dev
```

## 범위와 한계

- `smartstore-bridge`와 연결되어 있지 않습니다.
- 자동화 테스트가 없습니다.
- 상품 데이터와 이미지는 정적입니다.

전체 저장소 개요는 [`../README.md`](../README.md)를 참고하세요.
